# Mellow Booth. Photo Studio

这是一个无需后端的第一版在线大头贴网页原型。

## 运行方法
1. 解压 ZIP。
2. 用 VS Code 打开文件夹。
3. 推荐安装 VS Code 的 Live Server 扩展。
4. 右键 `index.html`，选择 **Open with Live Server**。
5. 在浏览器中允许摄像头权限。

也可以把 `index.html` 部署到支持静态网站的 HTTPS 托管平台。摄像头访问通常要求 HTTPS 或 localhost。

## 已实现
- 摄像头开启/关闭、倒计时、单张/两张/四张连拍
- 上传本地图片（支持多张）
- 原图、奶油柔光、日系胶片、暖调、黑白、清冷滤镜
- 基础柔肤感、亮度、对比度调整
- 四格、双格长条、双格方形布局
- 相框颜色、贴纸、文字
- PNG 下载
- 本地浏览器处理，不主动上传照片

## 当前原型的限制
- 美颜是基础柔化效果，不是 AI 人脸识别美颜。
- 贴纸目前位于相框底部，暂不支持拖动、缩放或旋转。
- 照片暂存在当前页面内存中，刷新页面后不会保留。
- 建议后续增加相框素材库、移动端镜像/摄像头切换、逐张照片替换、打印尺寸和部署配置。
